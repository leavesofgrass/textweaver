# Code blocks

Move the caret into each block with the Down arrow. Its first line names the
language, for example "code, Python".

```python
# Add two numbers.
def add(a, b):
    return a + b
```

```rust
// The same in Rust.
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

```
A block with no language says only "code".
```
