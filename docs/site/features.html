Features

This page lists what textweaver can do, grouped by topic. Each feature says whether it is done, partly done, or not there yet, and links to its guide.

The feature list needs JavaScript.

How the status is shown

Each status is written out in words, with its own shape and border style:

  • Done: a filled circle with a check mark, and a solid border.
  • Partial: a half-filled circle, and a double border.
  • Not yet: an empty dashed circle, and a dotted border.
