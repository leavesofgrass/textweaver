Keyboard shortcuts

Every textweaver command has a keyboard shortcut or runs from the command palette. Type in the search box, or use the filters, to find a shortcut. The same list is in the keyboard reference, which is made from the keymap itself.

Before you start

  • The command palette runs every command by name: press F2 (in the terminal also Alt+X or the colon key).
  • F9 turns single-key shortcuts off, so dictation or a switch keyboard never triggers a command by accident. Chords with Ctrl or Alt, the arrow and function keys, and the palette keep working.
  • The GUI keys shown are for Windows and Linux. On macOS the GUI uses Cmd wherever it shows Ctrl. Choose macOS under Platform to see Cmd in the GUI keys.
  • You can change any key in keymap.toml; see the keyboard reference.

Layers

What a key does depends on the mode you are in. Each shortcut belongs to a layer:

  • Global: chords that work in every mode.
  • Browse: single keys for reading, like a screen reader's browse mode.
  • Speech Cursor: keys for line-by-line reading; they take over browse keys with the same name while Speech Cursor is on.
  • Edit: keys for editing; in edit mode other keys type text.

The layers are explained in ADR-0006: Keymap, actions, and announcements.
